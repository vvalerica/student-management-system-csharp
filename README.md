# student-management-system-csharp# Catalog Studențesc – C# Windows Forms

Aplicație desktop realizată în C# pentru gestionarea unui catalog studențesc.

## Tehnologii utilizate
- C#
- Windows Forms
- MySQL
- SQL

## Funcționalități
- înregistrare studenți
- adăugare cursuri
- adăugare note
- modificare date student
- modificare cursuri
- conectare la baza de date

## Structură proiect
Proiectul conține interfață grafică Windows Forms, clase pentru gestionarea entităților și script SQL pentru baza de date.
